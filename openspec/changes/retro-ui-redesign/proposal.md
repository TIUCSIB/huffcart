# Proposal

## Why

v1 功能链路（播放、存档/快进）已跑通，但界面仍是"占位级"观感：纯文字列表、静态设置页、半透明浮层手柄，与产品定位（FC 复古模拟器）的怀旧气质不匹配。用户已用设计稿（"吹卡带"版）确定目标视觉——米白底 + 任天堂红 + 实体红白机元素的复古风，本次按设计稿把全 app 的 UI 一次到位。

## What Changes

- **全局主题翻转**：深色-only 改为米白浅色底 + 任天堂红顶栏 + 红色主按钮；像素字体（Press Start 2P / 融合像素）继续用于标题与品牌元素，正文系统字体。游戏屏保持黑色背景（游戏画面需要），品牌启动页保持红底。
- **品牌落地**：应用显示名 Huffcart → 「吹卡带」（huffcart 的直译，副标「FC 小霸王 · 经典回忆」，标语「按下开始键，回到童年」；包名/applicationId 不变）。
- **品牌启动页**：冷启动先展示红底全屏品牌页（像素字 Logo、主机插画、标语），短暂展示后自动进入首页；装饰元素全部代码绘制，不引入位图美术资源。
- **导航重构**：底部导航 3 tab = **首页 / 游戏库 / 我的**（设置并入「我的」tab）；新增路由：游戏详情页、分类页、按键设置页。
- **首页 tab**：红顶栏（品牌名 + 搜索 + 溢出菜单）+ 分类 chips + **2 列封面网格**；卡片含封面、标题、FC 角标与 ⋮ 菜单。
- **游戏库 tab**：**列表视图**（缩略封面 + 名称 + FC 角标），与首页同数据源，chips 与搜索行为一致——双视图按设计稿恢复。
- **分类页**：6 张彩色分类卡片（动作 / 射击 / 冒险 / 益智 / 格斗 / 赛车，像素风图标 + 主题色），从 chips 行「分类」入口进入，点卡片进该分类游戏列表。
- **移除游戏**：首页卡片菜单与详情页菜单提供「移除」（确认后删除 ROM 及其存档文件）——设计稿的卡片 ⋮ 不能是假入口。
- **游戏详情页**：hero 封面（播放浮层）、标题与标签、简介区（内置词典命中显示文案，未命中显示文件信息）、全宽红色「开始游戏」按钮。
- **游戏屏布局重排**：竖屏下上半为游戏画面区、下半为深色圆角控制面板（白色描边十字键、红色圆形 B/A、深灰 SELECT/START 胶囊、面板底部 FAMILY COMPUTER 装饰横幅）；横屏维持全屏 + 浮层。
- **设置改版**（我的 tab）：分组样式（模拟器 / 其他）+ 条目图标；「按键设置」为真实功能入口（映射预览 + 点按重绑 + 恢复默认），画面设置/声音设置/存档管理为禁用占位行（「即将推出」）；「关于我们」「清除缓存」可用。
- **物理键盘支持**：GameScreen 接收键盘事件并按用户映射（默认 ↑↓←→ / A→Z / B→X）驱动模拟器输入。

**范围裁剪**（设计稿有但本期不做，均为合理假设下的取舍）：详情页截图缩略图行（无真实截图来源）、真实游戏封面抓取（封面用 ROM 名确定性生成的像素风占位图）、游戏屏顶部品牌条与 ⚙️ 入口（游戏屏保持沉浸，设置从「我的」进入）、体育分类（设计稿 chips 与分类页不一致，统一为上述 6 类）、设计稿中 tab 根页面出现的返回箭头（mockup 噪音，tab 根不带回箭头）。

## Capabilities

### New Capabilities

- `game-library`: 游戏库的呈现层——封面网格（首页）、列表视图（游戏库）、分类筛选与分类页、搜索、游戏详情页、移除游戏。ROM 的导入与存储行为仍归 `game-playback`，本能力只管"看得见的部分"。

### Modified Capabilities

- `app-shell`: 「全局主题」由强制深色改为米白浅色 + 红顶栏（品牌启动页、游戏屏除外）；「应用启动与导航结构」改为品牌启动页 + 3 tab（首页/游戏库/我的）并增加新路由；新增「设置页结构」要求（我的 tab 承载设置 + 占位行规则）。
- `game-playback`: 「画面呈现」增加竖屏分区布局（游戏区 + 控制面板区）；「虚拟手柄输入」按设计稿重定视觉形态；新增「按键映射与物理键盘输入」要求。

## Impact

- `:app` 模块全部 UI 层：`ui/theme/*`（色板翻转 + 深红层次色）、`ui/HuffcartApp.kt`（导航表 + 启动页）、`ui/screens/*`（Home 网格 / Library 列表 / Categories / Detail / Mine / KeyMapping 新增或重写，Game 重排）、`res/values/strings.xml`（应用名）
- 新增少量纯 Kotlin 逻辑：分类与简介词典（内置 Map）、占位封面生成器（哈希取色/图案）、按键映射存取（SharedPreferences，零新依赖）、移除游戏的文件清理（roms/ + romsaves/）
- **不触碰** `:core-bridge` / `:core-native` / FCEUmm 构建链；无新第三方依赖；像素字体资源已有
- **协调点**：与在途 change `save-states-fastforward` 的交汇在 GameScreen——存/读/快进按钮组（其地盘）不动，本 change 只重排控制面板与画面分区；其反馈气泡配色随主题微调即可
