# Proposal

## Why

v1 功能链路（播放、存档/快进）已跑通，但界面仍是"占位级"观感：纯文字列表、静态设置页、半透明浮层手柄，与产品定位（FC 复古模拟器）的怀旧气质不匹配。用户已用设计稿确定目标视觉——"FC 小霸王"米白底 + 任天堂红顶栏的复古风，本次按设计稿把全 app 的 UI 一次到位。

## What Changes

- **全局主题翻转**：深色-only 改为米白浅色底 + 任天堂红顶栏 + 红色主按钮；像素字体（Press Start 2P / 融合像素）继续用于标题，正文系统字体。游戏屏保持黑色背景（游戏画面需要）。
- **品牌落地**：应用显示名 Huffcart → 「FC 小霸王」（包名/applicationId 不变）。
- **导航重构**：底部导航 2 tab → 3 tab（首页 / 游戏库 / 设置）；新增路由：游戏详情页、按键设置页。默认仍落在游戏库页。
- **首页 tab**：品牌页（红底大 Logo、FC 手柄插画、像素砖块装饰、slogan「那些年，我们一起玩过的游戏」），装饰元素全部代码绘制，不引入位图美术资源。
- **游戏库改版**（新能力 `game-library`）：封面网格墙（3 列）+ 分类筛选 chips（全部/动作/射击/冒险/格斗/体育/益智）+ 名称搜索；点游戏进详情页（hero 封面、标签、大号「开始游戏」按钮、文件信息）。
- **游戏屏布局重排**：竖屏下上半为游戏画面区、下半为深色圆角控制面板（十字键、红色圆形 A/B、Select/Start 胶囊），按下态红色高亮；横屏维持全屏 + 浮层。
- **设置页改版**：分组样式（模拟器 / 其他）；「按键设置」为真实功能入口（映射预览面板 + 点按重绑 + 恢复默认），画面设置/音频设置/存档管理为禁用占位行（「即将推出」），行为归后续 change。
- **物理键盘支持**：GameScreen 接收键盘事件并按用户映射（默认 ↑↓←→ / Z / X）驱动模拟器输入。

**范围裁剪**（设计稿有但本期不做，均为合理假设下的取舍）：专设分类页（chip 就地过滤即可）、详情页截图缩略图行（无真实截图来源）、列表/网格双视图（网格为唯一视图）、真实游戏封面与简介词典（封面用 ROM 名确定性生成的像素风占位图，简介仅内置常见游戏词典、未知游戏显示文件信息）。

## Capabilities

### New Capabilities

- `game-library`: 游戏库的呈现层——封面墙、分类筛选、搜索、游戏详情页。ROM 导入行为仍归 `game-playback`，本能力只管"看得见的部分"。

### Modified Capabilities

- `app-shell`: 「全局主题」由强制深色改为米白浅色 + 红顶栏；「应用启动与导航结构」由 2 tab 改为 3 tab 并增加新路由；新增「设置页结构」要求（分组布局 + 按键设置入口 + 占位行规则）。
- `game-playback`: 「画面呈现」增加竖屏分区布局（游戏区 + 控制面板区）；「虚拟手柄输入」按设计稿重定视觉形态；新增「按键映射与物理键盘输入」要求。

## Impact

- `:app` 模块全部 UI 层：`ui/theme/*`（色板翻转为浅色方案）、`ui/HuffcartApp.kt`（导航表）、`ui/screens/*`（Library/Settings/Game 重写，新增 Home/Detail/KeyMapping 屏）、`res/values/strings.xml`（应用名）
- 新增少量纯 Kotlin 逻辑：分类词典（内置 Map）、占位封面生成器（哈希取色/图案）、按键映射存取（SharedPreferences，零新依赖）
- **不触碰** `:core-bridge` / `:core-native` / FCEUmm 构建链；无新第三方依赖；像素字体资源已有
- **协调点**：与在途 change `save-states-fastforward` 的交汇在 GameScreen——存/读/快进按钮组（其地盘）不动，本 change 只重排控制面板与画面分区；其反馈气泡配色随主题微调即可
