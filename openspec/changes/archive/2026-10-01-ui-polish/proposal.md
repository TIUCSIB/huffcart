# Proposal

## Why

对照设计稿逐屏比对 MuMu 实机截图，当前实现与设计稿在导航观感、卡片布局、详情页与游戏屏结构上差距明显，影响整体品质感。本次按用户指出的四点做一轮界面精修。

## What Changes

- **底部导航**：选中态改为图标与标题整体同色（任天堂红），去除默认的淡紫色胶囊底与杂色背景；导航栏背景与米白主题统一（白底/米白底 + 顶部分隔线），不再"格格不入"。
- **库卡片结构统一**（首页网格与游戏库列表、详情页 hero 三处图片比例统一为 FC 原生 256:240）：首页卡片按设计稿重排——封面在上、标题行（名称 + ⋮ 菜单）在封面下方、FC 标签独占一行；FC 角标与 ⋮ 不再叠在封面上。
- **游戏详情页**：hero 封面移除中央播放按钮浮层（底部已有「开始游戏」）；「开始游戏」素材按钮增加按压质感（按下变暗 + 下沉位移）。
- **游戏屏结构重排**：新增顶部红色导航栏（左上吹卡带素材 logo、右上 ⚙️ 设置按钮）；存 / 读 / 快进从游戏画面区移除，收进 ⚙️ 展开的快捷菜单（保留三项功能与反馈，不再遮挡画面）；导航栏下方才是游戏画面区与控制面板区。
- **控制面板按键布局**按设计稿：十字键置于圆形凹槽（臂端三角箭头保留）；B / A 红色圆钮横向排列（B 左 A 右、大致同水平）；SELECT / START 小胶囊并排居中于面板下部；面板底部保留 FAMILY COMPUTER 红色横幅。

**范围裁剪**：不改导航信息架构（仍三 tab）、不改分类/搜索/词典逻辑、不做真实游戏截图封面（仍用确定性占位图）、存/读/快进功能行为本身不变（仅入口位置变化）。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `game-library`: 「游戏详情页」——hero 封面不再带播放浮层样式（去中央播放按钮）。
- `game-playback`: 「画面呈现」——竖屏结构由"画面区 + 控制面板区"改为"顶部导航栏 + 画面区 + 控制面板区"；「虚拟手柄输入」——按键布局描述更新（B/A 横排右侧、SELECT/START 居中并排）。

## Impact

- `:app` UI 层：`HuffcartApp.kt`（NavigationBar 配色与选中态）、`HomeScreen.kt` / `LibraryScreen.kt` / `LibraryCommon.kt`（卡片结构、封面比例常量）、`DetailScreen.kt`（去浮层、CTA 按压态）、`GameScreen.kt`（顶部导航栏 + ⚙️ 快捷菜单、chips 移除）、`PadControls.kt`（AbButtons 横排、MenuPills 居中、面板色）
- 不触碰 `:core-bridge` / `:core-native`；无新依赖
- 已归档能力兼容：`save-states` / `fast-forward` 的"游戏屏 SHALL 提供存/读/快进"由 ⚙️ 菜单承载，行为不变
