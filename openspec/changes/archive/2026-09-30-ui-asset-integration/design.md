# Design

## Context

素材库是单张 1536×1024 的 RGBA 整图，约 47% 像素完全透明（背景透明，之前看到的"黑底"只是查看器底色），试切验证 logo / 主机插画 / 像素按钮边缘干净、可直接切。当前 app 的品牌图形全部代码绘制（Canvas），观感为示意级。

用户决策：**纯视觉接入**（不加收藏/排序/确认弹窗等新功能）+ **混合策略**（大件美术切片，控件代码仿制）。

## Goals / Non-Goals

**Goals:**

- 启动页、空状态、详情 CTA、按键设置预览、游戏屏横幅五处视觉升级为素材库美术
- 切片素材随应用打包（`res/drawable-nodpi/`），无网络依赖
- 像素图缩放用最近邻采样（`FilterQuality.None`），保持锐利

**Non-Goals:**

- 不接入烤死文字且文案不符的素材（对话框、收藏/下载按钮）；不接入图标集与分类 chips 行（体育分类与现有 6 分类集合不符）
- 不做新功能（收藏、最近玩过/按字母排序、启动确认弹窗）——素材库暗示但明确排除，归后续 change
- 不用 9-patch 改造 AlertDialog 描边（收益低、改动面大）；现有 chips 选中态观感已达标，不动

## Decisions

1. **切片清单**（8 件，脚本切片 + bbox 收紧）：`asset_logo`（吹卡带+FC）、`asset_logo_sub`（副标徽章）、`asset_console`（主机+手柄，x 收到 252 避开右侧卡带元素）、`asset_banner_red`（红色云纹横幅条）、`asset_landscape`（像素场景条）、`asset_btn_start`（开始游戏按钮，烤字与现有 CTA 文案一致，可直接做图像按钮）、`asset_gamepad`（手柄套件，替换按键设置页 Canvas 预览）、`asset_cartridge`（卡带小图，INSERT CARTRIDGE 装饰）。统一放 `res/drawable-nodpi/`，Compose 里用 `dp` 显式定尺寸，规避密度目录的自动缩放歧义。

2. **烤字素材仅用于文案完全一致处**：「开始游戏」按钮是唯一烤字接入点（详情页 CTA）；其余位置一律图 + 可变文字叠加或纯代码。

3. **缩放纪律**：素材原始尺寸偏小（按钮 335×90、logo 471×182），在 3.5x 密度屏上约 1:1 至 1.3x 放大；`Image(filterQuality = FilterQuality.None)` 最近邻采样，像素风放大不糊。

4. **替换点与保守边界**：启动页删 `drawConsole`/`drawBricks`（Canvas 代码）换素材；空状态加场景条；CTA 由 Material `Button` 换可点击 `Image`（保留 `contentDescription` 无障碍语义）；游戏屏横幅保留 FAMILY COMPUTER 标签、底图换云纹条；按键设置页删 `PadPreview` Canvas 换套件图。不触碰导航、数据、游戏会话逻辑。

5. **游戏屏手柄适配（追加，用户要求）**：素材手柄图为静态图，无法表达逐键按下高亮（spec「虚拟手柄输入」要求按下 SHALL 红色高亮），故不做贴图手柄，而是代码仿制素材观感——色板取素材实测值（面板 #2C2C2C、凹槽 #333333、十字键 #373737、A/B #F22C2E + 底影 #C21E20、胶囊 #383838/#555455），十字键加凹槽圆与连续十字底座（四向命中区几何不变），A/B 加立体底影与按压下沉位移，横竖屏共用组件自动同步。

6. **手柄视觉 V2 重制（用户反馈样式差距大）**：对照用户提供的素材手柄清晰参考图逐元素采样重写 `PadControls`——十字键改 Canvas 绘制（凹槽圆 #252525 + 圆润十字臂 #3C3C3C + 臂端白色三角箭头，替换 Material chevron 图标），A/B 改垂直渐变红球（#F85753→#F22B2F→#C41E20）+ 底部投影 + 深红字母 #7A0305（替换白字母），SELECT/START 胶囊深描边 #191919 + 白粗体字。命中区为独立透明层，按下高亮（臂红/球提亮下沉）逻辑不变。

## Risks / Trade-offs

- [素材放大略糊（源图 1536 宽）] → 最近邻采样 + dp 尺寸贴合原始比例；如用户后续提供高清单件素材可逐个替换
- [启动页红底与素材红色系不完全一致] → 素材自带深红描边，在 `HcRedDark` 上仍有层次；真机截图验收把关
- [烤字按钮不可本地化/改文案] → 当前产品只有中文且文案固定；若未来改文案需换回代码按钮（设计已记录）

## Migration Plan

纯资源与 UI 层替换，一次提交；回滚 = revert。素材切片脚本可重跑（源图路径固定）。素材总量经调色板量化压缩至 75KB。**归档顺序依赖**：「品牌启动页」需求由在途 change `retro-ui-redesign` 引入，本 change 的 app-shell delta 修改它——须先归档 retro-ui-redesign 再归档本 change（validate 的 INFO 提示即此依赖）。
